# Learn - 待办事项管理应用

一个简单而实用的命令行待办事项管理应用，使用Python编写。

## 功能特性

- ✅ 添加新任务
- 📋 查看所有任务
- ✔️ 标记任务为完成
- 🗑️ 删除任务
- 💾 自动保存到JSON文件

## 使用方法

### 运行应用

```bash
python todo_app.py
```

### 功能说明

1. **添加任务**: 输入任务描述，系统会自动保存
2. **查看任务**: 显示所有待办事项及其状态
3. **完成任务**: 根据任务ID标记任务为已完成
4. **删除任务**: 根据任务ID删除任务
5. **退出**: 退出应用程序

## 数据存储

所有待办事项都保存在 `todos.json` 文件中，应用关闭后数据不会丢失。
