## 什么是 ChatBI

ChatBI 是雪球公司的智能数据分析系统，能够将自然语言需求自动转换为准确的 SQL 查询语句。

**核心价值**:
- ⚡ 提高效率: 从人工编写 SQL 到 AI 自动生成
- 🎯 保证准确: 基于知识库，符合业务定义和数据口径
- 📚 知识沉淀: 将业务知识和经验系统化
- 🔄 持续进化: 通过反馈不断学习和优化

## 工作流程

```
1. 用户提交需求
   ↓
2. AI 解析需求（提取指标、维度、时间等）
   ↓
3. AI 澄清需求（如有模糊点）
   ↓
4. AI 检索知识库（业务定义、表结构、参考案例）
   ↓
5. AI 生成 SQL（基于知识库）
   ↓
6. AI 验证 SQL（语法、逻辑、口径、性能）
   ↓
7. AI 输出结果（SQL + 说明）
   ↓
8. 收集反馈（持续优化）
```

- **准确率**: 85%+ 一次通过率

- **响应时间**: < 30 秒

- 人工: 需要 20 分钟（需要理解需求、选表、写 SQL）

## 适用场景

### ✅ 适合的场景

1. **日常监控**: DAU、MAU、新增等常规指标
2. **用户分析**: 留存、活跃、分层等
3. **渠道分析**: 渠道质量、渠道效果
4. **内容分析**: 发帖、互动、内容质量
5. **临时分析**: 各类临时数据需求

### ⚠️ 需要人工介入的场景

1. **全新的分析需求**: 知识库中没有相关信息
2. **特别复杂的需求**: 涉及多个业务系统、复杂计算
3. **需要业务判断的**: 需要结合业务背景做判断

## 与传统方式对比

### 传统方式（人工）

```
业务方提需求
    ↓
数据分析师接需求
    ↓
沟通澄清需求（可能多轮）
    ↓
分析师查表、写 SQL
    ↓
验证 SQL
    ↓
交付 SQL
    ↓
业务方反馈（可能需要修改）
```

**问题**:
- 时间长（10-30 分钟）
- 依赖个人经验
- 知识难以传承
- 重复性工作多

### ChatBI 方式（AI）

```
业务方提需求
    ↓
AI 自动处理（澄清、生成、验证）
    ↓
输出 SQL + 说明
```

**优势**:
- 快速（10-30 秒）
- 标准化（基于知识库）
- 可扩展（并发处理）
- 知识沉淀（持续积累）

## 技术选型

### 方案 1: Cursor + Rules（推荐用于验证）

**优点**: 实现简单，快速验证
**缺点**: 手动交互，不适合大规模使用

### 方案 2: Cloud Agent（推荐用于生产）

**优点**: 自动化，可集成到工作流
**缺点**: 需要配置

### 方案 3: 独立服务（长期方案）

**优点**: 完全自定义，可深度集成
**缺点**: 开发成本高
