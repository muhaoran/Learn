# 内容指标定义

> 本文档定义所有内容相关的数据指标。

## 发帖数

### 定义
统计周期内用户发布的帖子总数。

### 计算规则
```
发帖数 = COUNT(post_id)
WHERE 发布时间 >= 开始时间
  AND 发布时间 < 结束时间
  AND 帖子状态 = '正常'
```

### 数据口径
- **统计对象**: post_id
- **是否去重**: 不去重（统计总数）
- **是否包含删除的帖子**: [待补充]
- **是否包含审核未通过的帖子**: [待补充]

### 数据来源
- **推荐表**: `dws_content_daily`
- **明细表**: `dwd_post`

## 发帖用户数

### 定义
统计周期内发布过帖子的去重用户数。

### 计算规则
```
发帖用户数 = COUNT(DISTINCT user_id)
WHERE 发布时间 >= 开始时间
  AND 发布时间 < 结束时间
  AND 帖子状态 = '正常'
```

### 数据口径
- **统计对象**: user_id
- **去重规则**: 按 user_id 去重

---

## 人均发帖数

### 定义
平均每个发帖用户的发帖数量。

### 计算规则
```
人均发帖数 = 发帖数 / 发帖用户数
```

### 注意事项
- 分母是"发帖用户数"，不是"活跃用户数"
- 可以反映用户的内容生产活跃度

---

## 互动数

### 定义
统计周期内用户的互动行为总数。

### 计算规则
```
互动数 = COUNT(interaction_id)
WHERE 互动时间 >= 开始时间
  AND 互动时间 < 结束时间
  AND 互动类型 IN ('点赞', '评论', '转发', '收藏')
```

### 细分指标
- 点赞数
- 评论数
- 转发数
- 收藏数
