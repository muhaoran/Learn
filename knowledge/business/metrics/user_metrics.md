## DAU (Daily Active User) - 日活跃用户数

### 定义
某自然日内有任意行为的去重用户数。

### 计算规则
```
DAU = COUNT(DISTINCT user_id)
WHERE 行为发生日期 = 统计日期
  AND 行为类型 IN (登录, 浏览, 发帖, 评论, 点赞, 交易, ...)
```

### 数据口径
- **统计对象**: user_id
- **去重规则**: 按 user_id 去重，一个用户一天只计一次
- **时间范围**: 自然日 00:00:00 - 23:59:59
- **时区**: [补充标准时区]
- **行为范围**: 所有用户行为（具体见"活跃用户"定义）

### 数据来源
- **推荐表**: `dws_user_daily` (汇总表，性能好)
- **明细表**: `dwd_user_behavior` (明细表，可自定义行为类型)

### 使用场景
- 日常运营监控
- 趋势分析
- 同比/环比分析

### 注意事项
- 节假日会有波动
- 需要考虑异常值（如刷量）
- 与 MAU 配合使用可计算粘性

## 新增用户数

### 定义
某时间段内完成注册的去重用户数。

### 计算规则
```
新增用户数 = COUNT(DISTINCT user_id)
WHERE 注册时间 >= 开始时间
  AND 注册时间 < 结束时间
  AND 注册状态 = '成功'
```

### 数据口径
- **统计对象**: user_id
- **去重规则**: 按 user_id 去重
- **时间字段**: 注册完成时间（register_time）

## 次日留存率

### 定义
某日新增的用户中，在次日（D1）仍然活跃的用户占比。

### 计算规则
```
次日留存率 = D1 活跃用户数 / D0 新增用户数 * 100%

其中:
- D0: 注册日
- D1: 注册日 + 1 天
- D1 活跃: 在 D1 这天有任意行为
```

### 数据口径
- **分子**: D1 活跃的新增用户数
- **分母**: D0 新增用户数
- **活跃定义**: 同 DAU 的活跃定义
- **时间计算**: 按自然日计算

### 数据来源
- **新增用户**: `dwd_user_register`
- **活跃数据**: `dwd_user_behavior` 或 `dws_user_daily`

### 使用场景
- 评估产品留存能力
- 评估渠道质量
- 新功能效果评估

### 注意事项
- 需要等到 D1 结束才能计算完整的留存率
- 不同渠道的留存率差异较大
- 需要排除异常用户（如测试账号）

## 人均指标

### 人均发帖数

**定义**: 平均每个用户的发帖数

**计算规则**:
```
人均发帖数 = 总发帖数 / 用户数
```

**注意**:
- 用户数是指活跃用户数还是全量用户数？需要根据具体需求确定

### 人均互动数

**定义**: 平均每个用户的互动次数

**计算规则**:
```
人均互动数 = 总互动次数 / 用户数
```
