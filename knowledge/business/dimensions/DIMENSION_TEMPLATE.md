# 维度定义模板

> 维度是观察数据的角度或切面，用于分组和筛选

---

## 📋 什么是维度？

- ✅ 观察角度（如"新老用户"、"日/周/月"）
- ❌ 不是指标（指标是度量，维度是角度）
- ❌ 不是术语（术语是概念，维度是分类）

---

## 🔑 核心说明

### ⭐ 分类规则（最重要）

**什么是分类规则**：如何将数据划分到不同类别

**必须明确4个特性**：

| 特性 | 说明 | 示例 |
|------|------|------|
| **互斥性** | 一个数据只能属于一个类别 | 用户只能是新用户或老用户 |
| **穷尽性** | 所有数据都能分类 | 所有用户都能分为新/老 |
| **边界明确** | 边界值的归属清晰 | 注册=30天算新用户 |
| **默认值** | 无法判断时的处理 | NULL归为"未知" |

**示例**：
```
新老用户分类:

✅ 好的分类:
| 类别 | 条件 |
| 新用户 | 注册 <= 30天 |
| 老用户 | 注册 > 30天 |
- 互斥: ✅ 是
- 穷尽: ✅ 是
- 边界: 30天算新用户
- 默认: NULL归"未知"

❌ 不好的分类:
| 类别 | 条件 |
| 新用户 | 注册时间比较短 |  ← 不明确
| 老用户 | 注册时间比较长 |  ← 不明确
```

### 数据实现

**两种情况**：

1. **字段已存在** - 直接使用
2. **需要计算** - 用 CASE WHEN 计算

## 📊 完整示例

### 示例1: 时间维度 - 日

```markdown
## 日（Day）

**维度名称**: 日

**维度类型**: 时间维度

**别名**: 天、自然日

**定义**: 
自然日，从 00:00:00 到 23:59:59 的 24 小时。

**引用的术语**: 无

**分类规则**:
每个自然日是一个类别，格式 YYYY-MM-DD

- **互斥性**: ✅ 是
- **穷尽性**: ✅ 是
- **边界**: 23:59:59属于当天，00:00:00属于新一天
- **默认值**: 不适用

**数据实现**:
- **数据字段**: date
- **字段类型**: date
- **所在表**: 几乎所有表（分区字段）

**SQL 实现** (Trino):
```sql
-- 直接使用
WHERE date = date_add('day', -1, current_date)

-- 从 timestamp 提取
cast(behavior_time as date) as date
```

**使用场景**:
- 日常监控、趋势分析、同比环比

**与其他维度组合**:
- 日 + 渠道 → 每日各渠道数据
- 日 + 新老用户 → 每日新老用户对比

**维护信息**:
- 负责人: 数据部门
- 更新时间: 2024-01-01
```

### 示例2: 用户维度 - 新老用户

```markdown
## 新老用户

**维度名称**: 新老用户

**维度类型**: 用户维度

**别名**: 用户新鲜度

**定义**: 
按用户注册时间距今的天数，将用户划分为新用户和老用户。

**引用的术语**: 
- [新增用户](../glossary.md#新增用户)

**分类规则**:

| 类别 | 判断条件 | 说明 |
|------|---------|------|
| 新用户 | 注册 <= 30天 | 注册30天内 |
| 老用户 | 注册 > 30天 | 注册超过30天 |

- **互斥性**: ✅ 是（只能是新或老）
- **穷尽性**: ✅ 是（所有用户都能分类）
- **边界**: 注册=30天算新用户
- **默认值**: register_date 为 NULL 归为"未知"

**数据实现**:
- **数据字段**: register_date
- **字段类型**: date
- **所在表**: dwd_user_register, dws_user_daily

**SQL 实现** (Trino):
```sql
-- 实时计算
SELECT 
    CASE 
        WHEN date_diff('day', register_date, current_date) <= 30 
        THEN '新用户'
        ELSE '老用户'
    END as user_type,
    COUNT(DISTINCT user_id) as user_count
FROM dwd_user_register
GROUP BY user_type;
```

**使用场景**:
- 新老用户行为对比
- 渠道新老用户分布
- 新用户留存分析

**与其他维度组合**:
- 新老用户 + 日期 → 每日新老用户趋势
- 新老用户 + 渠道 → 各渠道新老用户分布

**维护信息**:
- 负责人: 数据部门
- 更新时间: 2024-01-01
```
